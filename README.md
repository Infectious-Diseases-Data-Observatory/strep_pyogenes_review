### SECULAR AND GEOGRAPHIC TRENDS OF PENICILLIN MINIMUM INHIBITORY CONCENTRATIONS FOR STREPTOCOCCUS PYOGENES: A SYSTEMATIC REVIEW

Repository for code & figures.

#### Objectives of paper:

To evaluate the secular and geographic trends of S. pyogenes susceptibility to penicillin, focussing on whether there has been a significant change in the reported MIC.

#### Contents:

The global presentation of studies and isolates (Figure 2) is in `map.R`.

MIC regression (Figures 3, 4, and ordinal regression in Supplementary Material) in the `.Rmd`.

Geographic trend of MIC at country level (Figure 5) is in `forest.R`.

All figures will be saved into `/figs/`. Data used or produced in analysis is stored in `/data/`.

`mic_data_load.R` is a preamble data cleaning script used for the analysis.
